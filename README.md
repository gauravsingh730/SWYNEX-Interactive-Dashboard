# Global Sales Performance Dashboard
## Project by Swaynx Technologies

**Overview**

A comprehensive sales analytics dashboard built 100% natively in Microsoft Excel.

Transforms raw international sales data into actionable business intelligence.

**Key Features**

**Revenue Trends:** Tracks year-over-year sales growth from 2011 to 2014.

**Regional Volume:** Highlights the highest-grossing global regions.

**Market Profitability:** Identifies top ROI markets like APAC and the EU.

**Country Rankings:** Pinpoints the top 10 countries driving overall sales volume.

### Tools Used

**Microsoft Excel (Data Cleaning, Advanced Formulas, PivotTables, PivotCharts)**
